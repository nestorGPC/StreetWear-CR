# StreetWear CR

StreetWear CR es una tienda virtual desarrollada como proyecto final del curso
Tecnologías y Sistemas Web II.

La aplicación está orientada a la venta de ropa, tenis, gorras y accesorios,
permitiendo administrar productos, categorías, usuarios, carrito de compras,
pedidos y pagos.

## Tecnologías utilizadas

- PHP 8.2
- Laravel 12
- SQLite
- Filament 5
- Spatie Laravel Permission
- Filament Shield
- Bootstrap 5
- JavaScript
- Vite
- Git
- GitHub

## Funcionalidades

Actualmente el proyecto cuenta con:

- Panel administrativo con Filament.
- Gestión de categorías.
- Gestión de productos.
- Control de inventario.
- Carga de imágenes.
- Catálogo público de productos.
- Vista individual de productos.
- Carrito de compras.
- Actualización de cantidades.
- Eliminación de productos del carrito.
- Cálculo de subtotal.
- Cálculo de impuestos.
- Cálculo de costos de envío.
- Control de roles y permisos con Spatie y Shield.
